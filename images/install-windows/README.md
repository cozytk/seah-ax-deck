# Windows 설치 안내 이미지

2026-09-10 설치 안내 보강에 사용. `claude-*.png`, `git-download.png`, `python-store.png`는 사용자가 첨부한 Windows 화면 원본이다. 파일의 픽셀은 수정하지 않았으며, `InstallCapture.vue`가 원래 장표의 바깥 제목·출처 영역을 제외한 화면 일부만 표시한다. 제공 이미지의 좌표는 2048×1153 표시 크기를 기준으로 지정한다.

| 파일 | 제공 자료 | 장표에서 보여 주는 부분 |
|---|---|---|
| claude-download.png | 첨부 2 | Windows x64·ARM64 다운로드 버튼 |
| claude-login.png | 첨부 3 | 채팅·Cowork·코드 탭과 로그인 후 응답 |
| claude-git-required.png | 첨부 4 | Code 로컬 세션의 Git 필요 메시지 |
| git-download.png | 첨부 5 | x64 Setup·ARM64 Setup 링크 |
| claude-restart.png | 첨부 6 | Windows 알림 영역의 Claude 아이콘 |
| claude-folder.png | 첨부 7 | 새 폴더 만들기 메뉴 |
| python-store.png | 첨부 8 | Microsoft Store 열기 |
| node-download-windows.png | 공식 웹페이지 직접 캡처 | LTS 선택과 Windows Installer (.msi) |

Node 캡처 출처: https://nodejs.org/en/download (2026-09-10). 실제 페이지 UI에서 Windows와 x64를 선택한 뒤 main 요소를 캡처했다. 슬라이드는 상단 LTS 선택과 하단 설치 파일 영역을 각각 표시한다. Windows에서 설치 프로그램을 실행한 화면은 아니다.

구버전 Git·Claude UI는 버튼 위치 참고 자료이며 버전이나 계정 정보는 현재 제품 사양의 근거로 쓰지 않는다. 첨부 9의 Python 3.13 강조 화면은 최신 Python Install Manager 안내와 혼동될 수 있어 사용하지 않았다.
