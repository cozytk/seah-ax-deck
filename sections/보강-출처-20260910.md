## 2차 요청 반영

기존 189장에 16장을 추가하고 「코드 리뷰 요청」 1장을 제거해 204장으로 구성했다. 테마는 그대로이며, 삭제 장표의 이미지를 제외한 기존 이미지 배치를 유지했다.

- CLAUDE.md를 독립 장표로 먼저 설명. 담을 내용·경로·구체적인 지침·덜어낼 내용 → 15분 비교 실습 → 기존 실제 캡처 → 자동 메모리 비교 순서. [Memory](https://code.claude.com/docs/en/memory), [Best practices](https://code.claude.com/docs/en/best-practices#write-an-effective-claude-md).
- 200줄은 채워야 할 분량이나 강제 한도가 아니라 문서가 권하는 크기 목표다. 관련 없는 매뉴얼·과도한 강조·모순·오래된 명령을 줄인다. 자동 메모리·개인/상위 지침은 A/B 비교의 조건으로 확인한다.
- 비교 자료는 가상 정지 기록(12·4·8분). after 폴더에만 CLAUDE.md를 직접 작성하며, 예상 확인 기준은 합계 24분·10분 이상인 12분 기록만 조치 대상·원인 미확인 표시다. 새로 실행한 Claude 응답을 캡처한 것으로 표현하지 않았다.
- Agent Teams: PowerShell의 현재 창에서 환경 변수를 켜고 in-process로 실행. 현재 공식 문서는 기본값 in-process, 패널 화살표·Enter 조작, 세션 종료 시 팀 정리 자동화를 설명한다. v2.1.178 이전의 TeamCreate/TeamDelete 절차를 새 장표에 넣지 않았다. [Agent Teams](https://code.claude.com/docs/en/agent-teams), [CLI 설치](https://code.claude.com/docs/en/quickstart).
- 수업 스킬: [Anthropic skills](https://github.com/anthropics/skills), [im-not-ai](https://github.com/epoko77-ai/im-not-ai), [taste-skill](https://github.com/Leonxlnx/taste-skill). 커뮤니티 확장은 Anthropic 제작 기능과 구분했다.
- [Caveman](https://github.com/juliusbrussee/caveman), [Ponytail](https://github.com/dietrichgebert/ponytail), [Superpowers](https://github.com/obra/superpowers)의 제작자 설명·설치법 확인. GitHub API 조회 시 Stars는 각각 104,553 / 133,359 / 284,002였다. 장표에는 반올림한 참고치와 날짜를 표기하며 설치 수·효과 보장으로 해석하지 않는다. Superpowers는 공식 마켓플레이스의 커뮤니티 제작 플러그인이다.
- [Google Workspace MCP](https://developers.google.com/workspace/guides/configure-mcp-servers)는 공식 Developer Preview. 제품별 원격 서버와 OAuth·Cloud 프로젝트·API 구성이 필요하다. [Notion MCP](https://developers.notion.com/guides/mcp/get-started-with-mcp)는 공식 호스팅 서버와 OAuth 경로를 사용한다. 연결 성공과 도구의 실제 호출을 구분한다.

- [Claude Code Remote Control](https://code.claude.com/docs/en/remote-control)은 로컬 실행을 유지하는 원격 접속이다. 대화형 --remote-control, 대화 중 /remote-control, 연결 대기 서버 remote-control을 구분했다. 휴대폰에 실행 환경이 옮겨간다고 설명하지 않는다.
- [Codex Remote connections](https://developers.openai.com/codex/remote-connections)는 현재 [ChatGPT Learn의 Remote](https://learn.chatgpt.com/docs/remote-connections)로 연결된다. 최신 문서가 안내하는 ChatGPT 데스크톱 앱 Settings → Connections와 모바일 Remote 흐름을 표기하고 구버전 명칭 차이를 명시했다. CLI에서 모바일 페어링을 한다고 쓰지 않았다.

새 비교 설명과 명령은 공식 문서·제작자 저장소에 근거한 강의 자료다. 실제 Windows 앱, 원격 페어링, Notion/Workspace 계정 연결을 이번 수정에서 실행한 것은 아니다.
