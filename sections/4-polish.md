# 화면 점검 6항목

<p class="lead">다 됐다는 말을 듣고 나서 <em>여섯 곳</em>을 직접 봅니다.</p>

| 볼 곳 | 어떻게 확인하나 |
|---|---|
| 첫 화면 | 3초 안에 어디를 봐야 할지 짚이는가 |
| 키보드 | Tab 을 눌렀을 때 지금 위치가 보이는가 |
| 숫자 | 자릿수가 세로로 맞는가 |
| 표 | 열이 많을 때 가로로 넘치지 않는가 |
| 빈 화면 | 데이터가 없을 때 무엇을 하라고 하는가 |
| 오류 | 엉뚱한 파일을 넣으면 무슨 말이 뜨는가 |

<p class="thesis">여섯 줄을 그대로 붙여넣어도 됩니다. 지시가 곧 체크리스트입니다.</p>
