## 수업 전에

- Windows에서 Claude 유료 계정 로그인, Git 설치, Node.js LTS 설치를 확인. 앱과 PowerShell을 다시 연다.
- 모델은 계정 목록에서 Opus를 우선 선택하되 한도가 부족하면 Sonnet. Fable 크레딧 추가 결제를 실습 조건으로 삼지 않는다.
- 강사는 Vercel 로그인·연결 저장소와 GCP 결제·API·IAM이 준비된 프로젝트를 사용한다. 학생에게 현장에서 GCP 권한 문제를 모두 풀게 하지 않는다.
- 기존 캡처는 Windows 외 환경도 포함한다. 키보드 안내는 Windows 표를 우선하고, 달라진 버튼은 현재 앱에서 확인한다.
- [샘플 ZIP](https://cozytk.github.io/seah-ax-deck/downloads/day1-samples.zip)을 내려받아 정상 파일과 누락 열 파일을 직접 열어 본다.

## 실습에서 놓치지 않을 것

역인터뷰 때 전체 불량률의 정의를 먼저 묻는다. A라인 100개 중 4개, B라인 200개 중 2개이므로 전체는 2%다. 2.5%가 나오면 비율의 단순 평균을 쓴 것이다. PRD에 전체 2%, A라인 4%, 필수 열 누락 시 안내를 완료 조건으로 남긴다.

스킬 이름을 입력한 것과 스킬을 실제로 읽은 것은 구분한다. 설치 파일과 작업 기록을 확인한 뒤 구현한다. Playwright MCP도 연결 표시만 보지 말고 브라우저 도구가 실제 호출됐는지 확인한다.

한도·네트워크·설치 문제로 실행을 못 한 경우에는 짝의 화면이나 강사 시연을 보고 검증 지시를 작성한다. 실행하지 못한 항목을 통과로 기록하지 않는다. 배포 전에는 공개 가능한 샘플만 사용하고, 배포 주소에서도 같은 샘플로 다시 확인한다.
